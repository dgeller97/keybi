## Workflow coverage

Each status describes a specific task exercised in the authoring UI. The Power BI references establish interaction and calculation expectations. The timing measurements are for KeyBI.

| Author task | Status | Evidence or boundary |
|---|---|---|
| Import personally selected CSVs with arbitrary headers | Pass | Multi-file picker, different schemas, quoted values, and a million-row fact file. |
| Model a star and two facts with shared dimensions | Pass | Product/Date → Sales and Period/Department → both Budget and Transaction. Both facts aggregate independently before their grouped results align. |
| Reuse measures under changing filter context | Pass | One margin definition in card and table. Ratio, difference, and variance percentage reevaluate at subtotal and total scope. |
| Build and format visuals, move and resize them | Pass for exercised types | Drag/drop or field selectors, aggregation, title, accent, number format, and editable geometry. The Gallery covers comparison, trend, distribution, detail and specialized visuals. |
| Apply slicers and independent visual/page/report filters | Browser-verified | Category plus date, independent selection clearing, inclusive date ranges, multi-select lists, editable interaction targets, and cross-filtered drillthrough. |
| Navigate editable multi-page reports | Pass | All five examples retain named page tabs. Back returns from drillthrough with the prior selection. |
| Drill down and drill through | Pass for tested paths | A bar hierarchy drills from category to product in the regression. A selected bar or matrix cell passes page, visual, row, column and slicer context into a detail page. Cross-report drillthrough remains outside the tested scope. |
| Build a paged detail table or a matrix | Browser-verified | Nested row and column levels, expand/collapse, multiple measures, subtotal visibility, grand totals, and numeric threshold colors. Each queried combination of levels displays up to 500 groups. |
| Rank a subset under changing period context | Pass | The server sorts the entire grouped result before taking the requested number. The top-five reference uses all 144 clinics, deterministic category tie-breaking, and both overall and February populations. |
| Save, restart, discover, reopen, and resave | Pass | The browser audit starts at the base URL, opens each card, changes an accent, saves, opens a fresh browser, and verifies the exact saved color and report numbers. The clean-workspace check also exercises first-launch seeding. |
| Author a prior-month comparison measure | Browser-verified | Reuse a base measure with a calendar field. The matrix total recomputes the overall rate, and drillthrough retains the current month, site, status and cohort. |

Power BI's matrix uses separate Rows, Columns and Values wells, and computes subtotals from underlying data. Its report drillthrough workflow opens a filtered detail page and supports returning to the source. Folio's selected-result **View records** action exposes that path directly.
